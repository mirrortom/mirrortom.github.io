Mssql Management Studio

测试环境: win10 / Management Studio 22

概述

官方经典的sqlserver管理工具,安装了该工具的22版本后发现,这和安装visual studio一样的了,安装程序是一个引导程序,大约4兆左右,是需要在线安装的.没有以前那种离线的安装包了.

22版本的界面和VS基本相似,是一个体系的了.这个版本比起以前2019年前的版本,启动速度快了很多,VS2026的启动也比VS2022快了好多.

如果觉得还是很重,还有VSCODE的MSSQL插件,安装插件后,可以很快的连接到本机sqlserver,日常的查询/建表功能都有的,简单的使用是很方便的了.

连接

连接到本机sqlserver,输入服务器名称,认证方式选择windows认证,点击连接就可以了.如果需要连接远程服务器,输入远程服务器的ip地址或者域名,认证方式选择sqlserver认证,输入用户名和密码就可以了.

连接本机时,那个"服务器名称"选项,和具体的sqlserver服务有关.例如安装的是sqlserver express版本,并且安装时选择的是"默认实例名",那么"服务器名称"输入本机名字或者localhost就可以了.如果安装时选择了"命名实例",那么后面要加入实例名.

// 服务器名称 本机默认实例
localhost

// 服务器名称 本机命名实例
localhost\实例名

// 连接本机localdb,(localdb)是固定写法,后面加入实例名
(localdb)\实例名
